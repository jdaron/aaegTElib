The `aaegTElib` library contains the TE consensus sequences identified in the *Ae. aegypti* AaegL5 reference genome. It is composed of four files:

1. **`aaegTElib.fna`**: FASTA file of the consensus sequences. Each header contains a sequence ID followed by a description giving the classification in three levels (class, order, superfamily).
2. **`aaegTElib.classification.txt`**: the classification of each consensus sequence, without the sequences.
3. **`aaegTElib.completness.txt`**: the status of each consensus sequence, either complete or fragmented.
4. **`aaegTElib.LTRcoordinate.txt`**: the coordinates of the LTRs on the consensus sequences.
